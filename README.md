# X SATURN – متصفح أندرويد (الإصدار 0.3.0)

## التشغيل
1. Android Studio (Koala أو أحدث) ← **Open** ← مجلد `XSaturn` ← انتظر Gradle Sync.
2. شغّل على هاتف (أندرويد 8.0+) أو محاكٍ. أو ارفع المشروع إلى GitHub وسيبني **Actions** ملف APK تلقائياً.
3. بعد أول تشغيل: افتح **لوحة X SATURN SECURITY** ← **تحديث القوائم الآن** (يحمّل قوائم الإعلانات/الضارة/الاحتيال/البالغين). التحديث الأسبوعي التلقائي مفعّل افتراضياً.

| **X SATURN SECURITY** | لوحة: مفاتيح كل ميزة، إجمالي/اليوم، حسب النوع، آخر 7 أيام، أكثر النطاقات حجباً، آخر النشاطات، تحديث القوائم، استيراد قوائم، المواقع المستثناة. كل رقم يأتي من حجب فعلي ويُخزَّن محلياً. |

## البنية (`app/src/main/java/com/xsaturn/browser`)
| المسار | الدور |
|---|---|
| `MainActivity.kt` | الشاشة الرئيسية (كما كانت) + ربط الحارس والدرع |
| `SecurityActivity.kt` (جديد) | لوحة X SATURN SECURITY |
| `SettingsActivity.kt` | إعدادات البحث والخصوصية (تغيّرت وظيفتها؛ كل إعدادات الحماية القديمة انتقلت للوحة الأمان) |
| `browser/XWebViewClient.kt` | اعتراض الطلبات، تحذير المواقع الخطرة، منع التحويلات |
| `browser/InternalPages.kt` (جديد) | يخدم صفحات البحث والتحذير من `assets/search` |
| `browser/PopupGuard.kt` (جديد) | تثبيت `assets/js/popup_guard.js` قبل الصفحة (androidx.webkit) |
| `search/` (جديد) | `SearchService`، المزوّدات، `Http` |
| `security/` (جديد) | `ThreatEngine`، `UrlHeuristics`، `SecurityStats`، `ListUpdater` |
| `adblock/` | `AdBlocker` (يقرأ الآن القوائم المحدَّثة)، `CosmeticScript` |

تبعيتان جديدتان فقط: `org.jsoup:jsoup` (تحليل HTML) و`androidx.webkit:webkit` (حقن سكربت مبكر). لم تتغير أي تقنية أخرى.

## الاختبارات
- `gradle testDebugUnitTest`: حالات الكشف الاستدلالي وتحليل القوائم (`ThreatLogicTest`).
- سكربتا JavaScript وقوالب HTML اختُبرت أثناء التطوير في Chromium حقيقي.

## حدود يجب معرفتها
- لا مانع إعلانات يحجب 100٪؛ إعلانات نطاق الموقع نفسه ومشغّلات الفيديو قد تظهر.
- DuckDuckGo بلا مفتاح قد يطلب أحياناً تحقق «روبوت»؛ عندها يعمل Brave/SearXNG إن أُعدّا، أو يظهر خطأ واضح مع زر بديل.
- القوائم المدمجة للضار والتصيّد فارغة عمداً حتى أول تحديث (لا أُدرج نطاقات من الذاكرة). الكشف الاستدلالي يعمل دائماً.
- روابط مصادر القوائم في `ListUpdater.SOURCES`؛ إن تغيّر رابط ستُظهر اللوحة فشله بدقة.
- مفتاح Brave يُخزَّن في تفضيلات التطبيق الخاصة (غير مشفّرة).
